1. Theory Academy

## Important Safety Note

This app is an educational reference tool. Do not use beta app content as final authority for real electrical work. Always follow official code, utility requirements, manufacturer instructions, and qualified professional judgment.

## How to Send Feedback

Open:

```text
Settings → Send Beta Feedback
```

Please include:

- your phone model
- Android version
- screen name
- what went wrong
- expected result
- screenshot if possible through email app

## High Priority Feedback

Please report immediately if you find:

- wrong calculator result
- unsafe wiring instruction
- wrong quiz answer
- Urdu translation that changes technical meaning
- app crash
- broken diagram
- broken search result
