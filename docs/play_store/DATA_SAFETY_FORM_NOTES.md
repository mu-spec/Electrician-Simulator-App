# Google Play Data Safety Notes — VoltMaster Pro

Use this as a guide when filling the Play Console Data Safety form.

## Data Collection

Does the app collect or share user data?

Recommended answer for current build:

```text
No user data is collected or shared by the app.
```

## Local Data

The app stores data locally only:

- bookmarks
- saved calculations
- quiz results
- language preference
- recent searches

This data is not transmitted to the developer server.

## Permissions

### Internet

Used for:

- opening YouTube tutorial links
- opening email/support links
- package dependencies that may require network availability

### No Sensitive Permissions

Current app does not require:

- location
- camera
- microphone
- contacts
- SMS
- phone
- storage file browsing

## Account Creation

No account creation is required.

## Ads

No ads in current build.

## Analytics

No analytics SDK in current build.

## Crash Reporting

No crash reporting SDK in current build.

## Data Deletion

Local data can be deleted in-app:

```text
Settings → Clear Data
```

or by uninstalling the app.
